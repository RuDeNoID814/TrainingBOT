# Tense Trainer Bot v2.0

Telegram-бот для изучения всех 12 английских времён с помощью AI.
Каждый вопрос генерируется нейросетью — уникальные упражнения каждый раз.

## Возможности

### 4 типа упражнений
- **Квиз** — предложение с пропуском, 4 варианта ответа + объяснение на русском
- **Найди ошибку** — предложение с грамматической ошибкой, выбери исправление
- **Напиши предложение** — пишешь сам, AI проверяет грамматику и время
- **Daily** — вопрос дня, одинаковый для всех (обновление в 07:00 МСК)

### Режимы практики
- **Быстрая тренировка** — 5 вопросов за ~3 минуты
- **По времени** — 10 вопросов на конкретное время
- **Рандом** — 12 вопросов, по одному на каждое время
- **Найди ошибку** — отдельный режим по временам

### Обучение (система Лейтнера)
- 5 коробок с интервальным повторением (0, 1, 3, 7, 14 дней)
- Теория → мини-задание → квиз с подсказками → финальный тест
- 3 успешных сессии (≥80%) = переход в следующую коробку
- Автоматическое напоминание о повторении

### Геймификация
- **Streak** — серия дней занятий (учебный день с 07:00 МСК)
- **Ранги** — Новичок → Начинающий → Средний → Продвинутый → Мастер
- **Рейтинг** — глобальный и по группам (Present / Past / Future)
- **Никнейм** — можно скрыть @username в рейтинге
- **Профиль** — статистика по временам, прогресс обучения

### Справочные материалы
- **Шпаргалка** — все 12 времён с формулами
- **85 неправильных глаголов** — 4 группы: ABC, ABB, ABA, AAA
- **Теория** — формула, маркеры, примеры, формы, окончания для каждого времени

### Надёжность
- Мульти-модель fallback через OpenRouter (4 модели Gemini)
- Кэш всех вопросов в БД — работает даже без API
- Quiz-сессии в БД — переживают перезапуск бота
- SQLite WAL mode для конкурентного доступа
- Уведомления об ошибках админу в Telegram
- Обработка timeout, сетевых ошибок, двойных кликов, Conflict

## Установка

```bash
git clone <repo-url>
cd TrainingBot
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Настройка

Создай файл `.env` в корне проекта:

```env
TELEGRAM_TOKEN=your_telegram_bot_token
OPENROUTER_API_KEY=your_openrouter_api_key
ADMIN_ID=your_telegram_user_id
```

Для локальной разработки через прокси (опционально):

```env
HTTPS_PROXY=http://127.0.0.1:12334
GEMINI_API_KEY=your_gemini_api_key
```

## Запуск

```bash
python bot.py
```

## Деплой (Bothost)

1. Подключи GitHub-репо к [bothost.ru](https://bothost.ru)
2. Укажи переменные окружения: `TELEGRAM_TOKEN`, `OPENROUTER_API_KEY`, `ADMIN_ID`
3. Каждый `git push` в `main` = автоматический редеплой

## Структура проекта

```
bot.py                — точка входа, админ-команды (/bd)
config.py             — переменные окружения
handlers.py           — все обработчики (20+ экранов)
gemini_api.py         — OpenRouter API: генерация вопросов, проверка предложений
database.py           — SQLite: 9 таблиц (пользователи, кэш, Лейтнер, сессии)
tenses.py             — 12 времён (теория, формулы, маркеры, окончания)
irregular_verbs.py    — 85 неправильных глаголов по группам
prompts/              — промпты для AI (квиз, найди ошибку, проверка)
```

## Админ-команды

| Команда | Действие |
|---------|---------|
| `/bd` | Список всех команд |
| `/bd download` | Скачать файл БД |
| `/bd clear` | Сброс статистики (вопросы сохраняются) |
| `/bd reset` | Полный сброс БД |
| `/bd path` | Путь и размер БД |

## База данных (9 таблиц)

| Таблица | Назначение |
|---------|-----------|
| users | Пользователи, streak, никнейм |
| quiz_results | Результаты тестов |
| production_results | Результаты "напиши предложение" |
| question_cache | Кэш сгенерированных AI вопросов |
| daily_questions | Вопросы дня |
| daily_answers | Ответы пользователей на daily |
| user_seen_questions | Дедупликация вопросов |
| leitner_progress | Прогресс обучения (коробки Лейтнера) |
| quiz_sessions | Активные сессии (переживают перезапуск) |
