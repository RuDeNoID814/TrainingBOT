# Tense Trainer Bot

Telegram-бот для изучения английских времён с помощью AI.
Все вопросы генерируются нейросетью — каждый раз уникальные.

## Возможности

### Практика
- 12 видовременных форм (Present / Past / Future × Simple / Continuous / Perfect / Perfect Continuous)
- Квиз по конкретному времени (10 вопросов) или рандом (12 — по одному на каждое время)
- "Найди ошибку" — предложение с неправильным временем, выбери исправление
- "Написать предложение" — пользователь пишет, AI проверяет грамматику и время
- Daily — вопрос дня, одинаковый для всех (обновление в 07:00 МСК)

### Обучение
- Теория по каждому времени: формула, маркеры, примеры, формы, окончания
- Система Лейтнера (5 коробок, интервальное повторение)
- Мини-задание "напиши предложение" между теорией и квизом
- Подсказки в квизе (формула + маркеры)
- Финальный тест (10 вопросов) при достижении коробки 5
- Автоматическое повторение по расписанию (1, 3, 7, 14 дней)

### Геймификация
- Streak — серия дней занятий подряд (учебный день с 07:00 МСК)
- Профиль — ранг, статистика, прогресс обучения
- Рейтинг — глобальный и по группам (Present / Past / Future)
- Шпаргалка + 85 неправильных глаголов (4 группы: ABC, ABB, ABA, AAA)

### Надёжность
- Мульти-модель fallback через OpenRouter (4 модели Gemini)
- Кэш всех вопросов в БД — работает даже при недоступности API
- Уведомления об ошибках прямо в Telegram (ADMIN_ID)
- SQLite WAL mode для конкурентного доступа
- Обработка timeout, сетевых ошибок, двойных кликов

## Стек

- Python 3.12+
- python-telegram-bot v22
- OpenRouter API (Gemini models)
- SQLite

## Установка

```bash
git clone <repo-url>
cd TrainingBot
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Настройка

Создай файл `.env` в корне проекта:

```env
TELEGRAM_TOKEN=your_telegram_bot_token
OPENROUTER_API_KEY=your_openrouter_api_key
ADMIN_ID=123456789
```

`ADMIN_ID` — Telegram user_id администратора. Бот шлёт сюда уведомления об ошибках.
`OPENROUTER_API_KEY` — ключ от [openrouter.ai](https://openrouter.ai)

Для локальной разработки через прокси (опционально):

```env
HTTPS_PROXY=http://127.0.0.1:12334
GEMINI_API_KEY=your_gemini_api_key
```

## Запуск

```bash
python bot.py
```

## Деплой (Bothost)

1. Подключи GitHub-репо к [bothost.ru](https://bothost.ru)
2. Укажи переменные окружения: `TELEGRAM_TOKEN`, `OPENROUTER_API_KEY`, `ADMIN_ID`
3. **Подключи общее хранилище** (`/app/shared`) — БД будет сохраняться между редеплоями
4. Каждый `git push` в `main` = автоматический редеплой

БД автоматически создаётся в `/app/shared/bot.db` (если директория доступна), иначе — в `bot.db` рядом с кодом.

## Структура проекта

```
bot.py                — точка входа, Application + handlers
config.py             — переменные окружения
handlers.py           — все обработчики (меню, квиз, обучение, daily, профиль)
gemini_api.py         — OpenRouter API: генерация вопросов, проверка предложений
database.py           — SQLite: пользователи, результаты, кэш, Лейтнер
tenses.py             — 12 времён (теория, формулы, маркеры, окончания)
irregular_verbs.py    — 85 неправильных глаголов по группам
prompts/              — промпты для AI (квиз, проверка, найди ошибку)
```

## Админ-команды

- `/db` — скачать файл БД (только для ADMIN_ID)
- `/reset_db` — полностью очистить БД и создать пустую (только для ADMIN_ID)
```
